# 🏕️ JANA URPAQ OS 360° — Цифровая экосистема лагеря «Жаңа Ұрпақ»

Автономная операционная система управления образовательно-трансформационным лагерем нового поколения **«Жаңа Ұрпақ»** (Основатель: **Асхат Абжанов**) и структурированная база знаний бизнеса для работы с AI-агентами.

---

## 🚀 Быстрый старт

* **Запуск в 1 клик (Windows):** откройте файл [`Открыть_Jana_Urpaq_OS.bat`](./Открыть_Jana_Urpaq_OS.bat) или запустите [`index.html`](./index.html) в любом браузере.
* **Офлайн-режим:** система работает на 100% автономно без интернета и внешних серверов (все библиотеки находятся в папке [`app/lib/`](./app/lib/)).
* **Тестовый Мастер-ПИН Администратора:** `7777` (кнопка **«⚙️ Админка»** в верхней шапке).

## 🌟 Ключевые возможности системы (v2.4)

1. **Консоль Основателя и Руководителей:** сквозной контроль двух департаментов (**«ТренОтдел»** и **«ОргОтдел»**), живой кадровый пульс 32 сотрудников и мониторинг вечерних SLA-отчётов.
2. **Персональные чек-листы для всех 15 ролей:** разделены на 3 этапа (*«До смены / Предкемп»*, *«Во время смены / Ежедневно»*, *«После смены / Сдача»*) с прогресс-баром и обязательным объяснением причин при срыве задачи.
3. **База знаний «Книга ЖУ»:** 12 Красных линий безопасности, 10 протоколов решения кризисов и 28 пошаговых руководств (с копированием для Google Docs).
4. **Панель Администратора (RBAC):** управление кадрами смены, функция имперсонации *«Войти как он»*, визуальный редактор документов и экспорт/импорт конфигурации.
